## 🧠 AI & Machine Learning Projects

**NLP & Large Language Models**
- [Multimodal Summarization](https://github.com/ArmyUser/Multimodal-Summarization): Multimodal (text + audio) summarization with Gemma and Qwen. Includes inference with greedy, beam search and temperature sampling, fine-tuning of Gemma on XSum and SAMSum, and evaluation with ROUGE plus qualitative analysis.
- [GenSPP × ERASER Benchmark](https://github.com/kor80/gen-spp-benchmark): Training GenSPP (Genetic Select-then-Predict Pipeline) on ERASER datasets (Movies, e-SNLI) and evaluating the extracted rationales with the official ERASER metrics.
- [Sexism Detection](https://github.com/t-perniola/Assignments-NLP): Sexism detection using RNNs, Transformers and prompting techniques.

**Fairness & Responsible AI**
- [Fair Candidate Screening System](https://github.com/kor80/Fair-Candidate-Screening-System): Fairness-aware ML for candidate screening, comparing bias-mitigation techniques such as reweighing, FaUCI and learned fair representations while preserving predictive performance.

**Decision Making & Game AI**
- [TablutAI](https://github.com/ArmyUser/TablutAI): An AI agent that plays Tablut, the strategic board game inspired by the Viking game Hnefatafl.
- [CDMO Project](https://github.com/t-perniola/CDMO-project): Combinatorial Decision Making and Optimization project developed at UniBo.
